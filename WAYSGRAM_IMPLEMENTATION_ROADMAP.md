# WaysGram — план реализации

Источник требований: `telegram.txt` из Library.

## Правила объёма

- Раздел 20 «Рекламная платформа» исключён целиком по решению пользователя.
- Все пункты, связанные с QR-кодами и QR-подключениями, исключены во всех разделах.
- Раздел 13 отсутствует в исходном файле; содержание не дополняется предположениями.
- Общий пользовательский тест проводится только после закрытия всех включённых этапов.
- Встроенные возможности базового Telegram-клиента и отдельные WaysGram API-функции учитываются отдельно; наличие UI без собственной серверной логики не считается завершённой интеграцией.

## Статусы

- `[ ]` — не завершено / не подтверждено.
- `[~]` — реализовано частично, требуется дополнение.
- `[x]` — этап закрыт после завершения реализации; тестирование приложения будет позже.

Backend-тесты прошли; финальная APK/устройственная проверка отложена до завершения всех этапов.

- [x] Уникальные характеристики подарков: при первом улучшении сервер WaysGram назначает редкость, модель, символ и фон; характеристики неизменны при последующих улучшениях, передаче и перепродаже. Старые улучшенные подарки получают характеристики автоматически при запуске backend.
- [x] Передача коллекционных подарков по username/ID и отправка вложением в личный чат.
- [x] Фиксированная перепродажа поддерживаемых коллекционных подарков за Gram.
- [x] Покупка подарков за внутренние WaysGram Stars.
- [x] Аукционы коллекционных подарков: backend и Android-интерфейс реализованы; ставки в Gram резервируются, предыдущий лидер получает возврат, по окончании торгов тот же серийный экземпляр переходит победителю. Участие разрешено только моделям подарков, которые исторически выпускались через аукцион Telegram: такие модели сохраняются в отдельном append-only реестре, независимо от текущей доступности каталога и наличия активных аукционов Telegram. APK успешно собран и прошёл проверку в CI; ручной пользовательский тест приложения остаётся частью общего тестирования после реализации этапов.
- [x] Чек о покупке в «Избранном» как сообщение с коллекционным вложением: серверная запись и отображение подтверждены; повтор покупки с тем же ключом не создаёт дубликат и не списывает Stars повторно (117 backend-тестов прошли на Python 3.11 и 3.12).
- [x] Управление каталогом из админ-панели AuthBot по Telegram Gift ID, включая цену и остаток.

**Граница реализации:** Telegram Gift ID используется как источник каталожных метаданных. Инвентарь, серийные номера, владельцы, внутренние Stars, Gram, улучшения и сделки принадлежат WaysGram и обрабатываются его backend; это не передача NFT в блокчейн Telegram.

**Система характеристик:** редкость распределяется по весам (60% обычная, 25% необычная, 10% редкая, 4% эпическая, 1% легендарная). Модель, символ и фон генерируются на стороне сервера и сохраняются в экземпляре подарка.
