# Темы чата: каналы и группы поверх кастомизации

Решение пользователя: «основ­ные темы каналов — поверх кастомизации, если тема
есть; если нет — как обычно». До этого каталог тем приходил от Telegram
(`account.getChatThemes`), у WaysGram-сервера его не было, поэтому выбрать тему
было нечего и кастомизация фона оставалась единственным оформлением.

## Каталог

`WaysGramChatThemes` собирает восемь «основных» тем: Fire, Ocean, Forest, Sakura,
Grape, Sunny, Frost, Night. У каждой:

* эмодзи (`🔥`, `🌊`, …) — он же ключ темы (`ThemeKey.ofEmoticon`);
* палитра: акцент, цвет пузырей, градиент фона для светлой и тёмной схемы;
* две записи настроек (`TL_themeSettings`) с `TL_wallPaperNoFile`, поэтому тема
  не тянет ни одного файла из сети.

`account.getChatThemes` отвечает этим каталогом (вместо `METHOD_NOT_SUPPORTED`),
поэтому штатный выбор темы чата в Telegram-клиенте показывает темы и сохраняет
выбор обычным механизмом.

## Хранение

`messages.setChatTheme` → `PUT /api/chats/{id}/theme` (`{"emoticon": "🌊"}`;
пустое тело снимает тему). Хранится в таблице `chat_themes`. Права: канал —
владелец или администратор, группа — участник. `GET /api/chats/{id}/theme`
возвращает выбранную тему.

Тема, выбранная на другом устройстве, подтягивается при открытии чата:
`ChatActivity.restoreWaysGramChatTheme()` читает её и применяет штатным
`setChatThemeEmoticon`.

## Приоритет над кастомизацией

Кастомизация отвечает только за общий фон приложения и за чаты без темы.
Если у чата есть тема, `ChatActivity.updateBackground()` выходит раньше, чем
берёт картинку кастомизации: фон, пузыри и служебные цвета задаёт тема. Вкладка
«Список чатов» и настройки по-прежнему показывают кастомизированный фон.

## Ограничения

* Темы оформления приложения (акценты, палитры интерфейса) не реализованы — это
  отдельная функция.
* Пересылка темы между установками работает только для каналов и групп через
  `/api/chats/{id}/theme`; личные чаты тему не хранят.
* На устройстве поведение не проверялось.
