# Анимация модели WaysGram (подарок Plush Pepe)

Модель `WaysGram` — единственная, у которой нет документа в каталоге Telegram: её анимация
целиком наша. Разбор ниже объясняет, как она собирается и почему модель сначала выглядела
мелкой, а в «Моих подарках» не рисовалась вообще.

## Что это за анимация

* Арт — `authbot/assets/gift_models/5936013938331222567/preview.png` (авторский пепе WaysGram
  с сердцем). Анимация авторская: пепе дышит и покачивается, за ним пульсирует мягкое
  свечение, вокруг вспыхивают звёздочки, вверх поднимаются три сердечка.
* Формат — WebM (VP9) с альфа-каналом, 512×512, 30 fps, 3 с, 90 кадров. Все кривые
  замыкаются за один цикл, поэтому петля без шва.
* Почему не TGS: анимация — один растровый слой, а `tlottie` в приложении рисует только
  векторные кадры. Lottie с image-слоем даёт пустую карточку (на это уже наступали).

Один и тот же файл живёт в двух местах и обязан совпадать байт в байт:

| Где | Путь |
| --- | --- |
| APK (встроенная анимация) | `TMessagesProj/src/main/res/raw/waysgram_model.webm` в архиве `WaysGram-Android.zip.part*` |
| Сервер (атрибут `model`) | `authbot/assets/gift_models/5936013938331222567/waysgram.webm` + `manifest.json` (`sha256`, `bytes`) |

## Как пересобрать

```bash
python3 scripts/build_waysgram_gift_model_webm.py \
    --art authbot/assets/gift_models/5936013938331222567/preview.png \
    --out authbot/assets/gift_models/5936013938331222567/waysgram.webm \
    --raw /path/to/WaysGram-Android/TMessagesProj/src/main/res/raw/waysgram_model.webm
```

Скрипт сам обновляет `sha256`/`bytes` в `manifest.json`. Нужны Pillow и ffmpeg
(подойдёт `imageio-ffmpeg`: скрипт находит его сам, либо передайте `--ffmpeg`).

## Почему модель была мелкой

`StarGiftSheet` (карточка уникального подарка: «Plush Pepe #???», `Model / Symbol /
Backdrop`, «Transfer»/«Wear») отводила модели квадрат 160 dp, да ещё и сам арт занимал
меньше половины кадра — прозрачные поля вокруг рисунка. Теперь квадрат — `MODEL_IMAGE_SIZE_DP
= 208`, а арт в WebM заполняет почти весь кадр (`ART_FILL` в скрипте). Вместе это даёт модель
примерно вдвое крупнее на том же месте карточки.

## Почему в «Моих подарках» не было модели

Ячейка `GiftSheet.GiftCell` запрашивала арт с фильтром `80_80_nolimit_pcache`. `pcache`
означает «брать кадры из `BitmapsCache`», а покадровый кэш строится медиа-стеком только для
документов Telegram. У модели WaysGram документ синтетический (файл лежит в
`files/waysgram_gifts/<id>.bin` и отдаётся транспортом), кэш кадров для него пуст — и
`AnimatedFileDrawable` не рисовал ничего. В карточке подарка фильтр был обычный, поэтому там
та же модель была видна.

Теперь ячейки (и превью апгрейда в `StarGiftPreviewSheet`) для видео-арта идут без `pcache`:
кадр берётся из файла, а WebM с альфой листает штатный видеодекодер.

## Почему модель всегда берётся из приложения

`WaysGramProfileGiftsController` собирает инвентарь из `/api/gifts`. Документ модели
резолвился с сервера, и если файла не было на диске, атрибут просто не добавлялся — ячейка
оставалась пустой карточкой с фоном и лентой «#???». Встроенная анимация есть всегда, поэтому
для модели WaysGram (по имени или по id документа) она побеждает любой серверный документ.
