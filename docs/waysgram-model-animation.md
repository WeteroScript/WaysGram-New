# Анимация модели WaysGram (подарок Plush Pepe)

Модель `WaysGram` — единственная, у которой нет документа в каталоге Telegram: её арт
отдаёт WaysGram и приложение возит с собой. Движение при этом **не авторское**: оно
полностью повторяет штатную анимацию Plush Pepe из каталога Telegram.

## Что это за анимация

* Источник движения — `authbot/assets/gifts/5936013938331222567.tgs`, оригинальный
  стикер подарка Plush Pepe (`tgs/by_name/plush_pepe.tgs` в каталоге). `rlottie`
  рендерит каждый кадр с исходными ключами и кривыми: покачивание корпуса,
  дыхание, движение рук, ног, глаз и сердца. Тайминг не менялся: 60 fps, `ip 60` →
  `op 240`, ровно 3 с, 180 кадров.
* Что дорисовано WaysGram: розовое сердце перекрашено в красное, на него
  нанесён логотип `WaysGram` (он следует за исходной трансформацией слоя `heart`),
  а по всему силуэту восстановлен **чёрный наружный контур** — его не было в
  предыдущей версии модели.
* Формат — WebM (VP9) с альфа-каналом `ALPHA_MODE=1`, 512×512, 60 fps, 3 с.
  Первый и последний кадры совпадают, поэтому петля без шва.
* Почему не TGS: арт теперь растровый (перекрашенное сердце, логотип, контур), а
  `tlottie` в приложении рисует только векторные кадры. Lottie с image-слоем
  даёт пустую карточку — на это уже наступали.

Один и тот же файл живёт в двух местах и обязан совпадать байт в байт:

| Где | Путь |
| --- | --- |
| APK (встроенная анимация) | `TMessagesProj/src/main/res/raw/waysgram_model.webm` в архиве `WaysGram-Android.zip.part*` |
| Сервер (атрибут `model`) | `authbot/assets/gift_models/5936013938331222567/waysgram.webm` + `manifest.json` (`sha256`, `bytes`) |

## Как пересобрать

```bash
python3 -m pip install pillow imageio-ffmpeg rlottie-python
python3 scripts/build_waysgram_gift_model_webm.py \
    --raw /path/to/WaysGram-Android/TMessagesProj/src/main/res/raw/waysgram_model.webm
```

Скрипт берёт TGS из `authbot/assets/gifts/5936013938331222567.tgs`, пересобирает
`preview.png`, перезаписывает WebM и сам обновляет `sha256`/`bytes`/`source` в
`manifest.json`. Нужны Pillow, `rlottie-python` и ffmpeg (подойдёт
`imageio-ffmpeg`: скрипт находит его сам, либо передайте `--ffmpeg`).
Файл из `--raw` затем надо положить в `TMessagesProj/src/main/res/raw/waysgram_model.webm`
внутри `WaysGram-Android.zip.part*`.

## Почему модель была мелкой

`StarGiftSheet` (карточка уникального подарка: «Plush Pepe #???», `Model / Symbol /
Backdrop`, «Transfer»/«Wear») отводила модели квадрат 160 dp, а старый авторский арт
занимал меньше половины кадра. Теперь квадрат — `MODEL_IMAGE_SIZE_DP = 208`, а
рендер original TGS занимает весь кадр 512×512, как и у остальных моделей подарка.

## Почему в «Моих подарках» не было модели

Ячейка `GiftSheet.GiftCell` запрашивала арт с фильтром `80_80_nolimit_pcache`. `pcache`
означает «брать кадры из `BitmapsCache`», а покадровый кэш строится медиа-стеком только для
документов Telegram. У модели WaysGram документ синтетический (файл лежит в
`files/waysgram_gifts/<id>.bin` и отдаётся транспортом), кэш кадров для него пуст — и
`AnimatedFileDrawable` не рисовал ничего. В карточке подарка фильтр был обычный, поэтому
там та же модель была видна.

Теперь ячейки (и превью апгрейда в `StarGiftPreviewSheet`) для видео-арта идут без `pcache`:
кадр берётся из файла, а WebM с альфой листает штатный видеодекодер.

## Почему модель всегда берётся из приложения

`WaysGramProfileGiftsController` собирает инвентарь из `/api/gifts`. Документ модели
резолвился с сервера, и если файла не было на диске, атрибут просто не добавлялся — ячейка
оставалась пустой карточкой с фоном и лентой «#???». Встроенная анимация есть всегда, поэтому
для модели WaysGram (по имени или по id документа) она побеждает любой серверный документ.


## Порядок слоёв и место надписи (25.11, финальное решение)

С устройства: «надпись дёргается», «часть руки поверх сердца», «сделай посередине сердца»,
затем прямо: «чтобы надпись была пониз рук, но прямо на сердце. Без разницы что её не видно».

- Порядок слоёв как в исходном стикере: контур → тело → **правая кисть (слой 15)** →
  **сердце** → **надпись** → левые кисти (1, 2). Надпись лежит на сердце, но под кистями.
- Положение — ровно середина сердца (0.50 по высоте, центр по горизонтали). Обрезка по
  силуэту сердца гарантирует, что буквы всегда «прямо на сердце».
- Так как кисти проходят по сердцу полосой через его середину, надпись в середине скрыта
  почти целиком — это осознанное решение пользователя (важно положение и порядок слоёв, а
  не читаемость). Кадры: `docs/assets/waysgram-wordmark-middle.png`.
- Крепление жёсткое: размер один раз, положение и наклон каждый кадр — из трансформа
  сердечного слоя; локальная точка постоянна, поэтому надпись не болтается.
