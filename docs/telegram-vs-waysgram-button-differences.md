# Какие кнопки отличаются: Telegram vs WaysGram
> **Исторический срез.** Это сравнение состояния до правки, которая удалила WaysGram-кнопки
> и вернула стоковые позиции. Текущее состояние описано в `docs/waysgram-fix-plan.md` и
> проверяется `scripts/test_android_stock_channel_group_buttons.py`.


Сравнение по фактической сборке из `WaysGram-Android.zip.part1…part5`. APK не собирался.
Обозначения: **+** — WaysGram-кнопка, которой нет в стоке; **−** — стоковая кнопка скрыта в WaysGram;
**↻** — кнопка есть, но открывает другой экран/диалог; **⚠** — кнопка есть, но не работает как в стоке
из-за незаполненных данных.

> Важно: кастомные пункты для «группы» добавляются только если `!ChatObject.isChannel(currentChat)`,
> то есть в обычной группе, **не в супергруппе/мегагруппе** (`ChatActivity.java:4623-4627`,
> `ChatEditActivity.java:906,914`). Мегагруппа не получает эти пункты, но теряет стоковый буст.

## 1. Меню «⋮» в чате

| Кнопка | Telegram | WaysGram | Тип |
|---|---|---|---|
| Уведомления / звук | есть | есть, без изменений | — |
| Поиск | есть | есть | — |
| **Усилить канал / Усилить группу** (`boost_group`) | показывается по premium/бустам/админке | **не показывается вообще**: `!WaysGramTransport.ENABLED` | − |
| **Direct Messages** / открыть чат предложений | показывается при `linked_monoforum_id != 0` | никогда не показывается: поле не заполняется маппером | − |
| Перевод, жалоба, «Просмотр как темы», обои, очистить историю, выйти/удалить | есть | есть, на своих местах | — |
| **Розыгрыши** | — | broadcast-канал | + |
| **Сообщения канала** / **Написать каналу** | — | broadcast-канал, открывает свой inbox | + |
| **Темы канала** | — | broadcast-канал | + |
| **Payment history** | — | broadcast-канал; нет RU-перевода, поэтому английская | + |
| **Бусты** | — | broadcast-канал и обычная группа, открывает свой REST-диалог | + |
| **Истории группы** | — | обычная группа | + |
| **Отправить от имени…** | — | обычная группа | + |
| **Темы** | — | обычная группа | + |

Источники: `ChatActivity.java:4513-4518` (скрытие стокового буста), `4611-4629` (новые пункты),
`WaysGramChats.java` — в нём нет `linked_monoforum_id`.

## 5. Экран «Изменить»

### Канал

| Строка-кнопка | Telegram | WaysGram | Тип |
|---|---|---|---|
| **Местоположение** | только у мегагрупп | появляется и у broadcast-канала, если `can_set_location` | + |
| **Welcome Message** | по праву `MANAGE_WELCOME` | скрыта: WaysGram не поддерживает ephemeral API | − |
| **Статистика и бусты** | по типу канала | скрыта при включённом WaysGram-транспорте | − |
| **Обсуждение** | открывает `ChatLinkActivity` | открывает REST-диалог привязки `WaysGramDiscussions.settings()` | ↻ |
| **Платные реакции** | — | своя строка, REST-диалог | + |
| **Статистика канала** | — | своя строка | + |
| **Настройки входящих канала** | — | своя строка | + |
| **Передать канал** | — | своя строка | + |
| **Темы канала** | — | своя строка | + |
| **Платная подписка** | — | только приватный канал | + |

Эти WaysGram-строки вставляются **между «Администраторами» и «Подписчиками»**
(`ChatEditActivity.java:1426-1428`), а не после всех стоковых.

|---|---|---|---|
| **Welcome Message** | по праву | скрыта | − |
| **Ограничения отправки** | — | создатель или админ с `change_info` | + |
| **Список участников** | — | только создатель | + |
| **Статистика группы** | — | только создатель | + |

Источники: `ChatEditActivity.java:906-1006, 1010-1021, 1342-1357, 1405-1412, 1426-1428, 1503-1509`.

## 6. Настройки реакций

| Кнопка | Telegram | WaysGram | Тип |
|---|---|---|---|
| **Enable Paid Reactions** внутри «Реакций» | по `paid_media_allowed` | не показывается: WaysGram-маппер не заполняет `paid_media_allowed` (только `paid_reactions_available`) | − |
| Стоковые эмодзи-реакции | есть | есть | — |

Вместо стокового тумблера работает отдельная строка «Платные реакции» в «Изменить» и пункт в меню поста.
Источники: `Components/Reactions/ChatCustomReactionsEditActivity.java:318-334, 460-462`,
`WaysGramChats.java:1464-1465`.

## 7. Экраны создания канала/группы

Видимых кнопок, которые отличаются от Telegram, нет. Отличается только загрузка пригласительной
ссылки: она идёт через REST (`ChannelCreateActivity.java:934-951`).

## Итог по кнопкам

- **Убраны:** буст из «⋮», Direct Messages, подарок каналу, предложить пост, голосовой чат/трансляцию,
  Welcome Message, «Статистика и бусты», стоковый тумблер платных реакций, список пользователей, поставивших реакцию.
- **Добавлены:** 5 пунктов в меню канала, 4 в меню обычной группы, 2 пункта в меню поста,
  «Медленный режим» в карточке группы, 6 строк в редактировании канала, 3 строки в редактировании группы.
- **Изменено поведение:** статистика, обсуждение, комментарии к посту, привязка группы обсуждений.
- Из-за незаполненных полей часть кнопок может отсутствовать даже там, где функциональность бэкенда есть.
- Часть новых подписей английская: `Payment history`, `Boost Channel` и др. — в `values-ru` нет ключей.
