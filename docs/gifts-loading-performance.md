# Загрузка моделей коллекционных подарков

Загрузка ускорена без изменения выбранных характеристик и без угадывания модели:

- Android проверяет кеш на устройстве прежде, чем ставить файл в очередь; совпадающие запросы по названию и ID используют общий ключ документа и одну загрузку. Три потока скачивания остаются ограниченными.
- Запросы метаданных разных коллекций идут максимум в трёх потоках; запрос фоновой подготовки каталога не занимает эти потоки.
- Частичный ответ кэшируется сервером 60 секунд вместо пяти минут. Клиент проверяет снова примерно через 62 секунды, только если открытый инвентарь ждёт отсутствующий атрибут; не более двух автоматических повторов подряд. Неполные данные по-прежнему не используются для угадывания другого документа по позиции или вероятности.
- Для строго ограниченного списка заранее идентифицированных документов (сейчас Shield of Sun) сервер сначала запрашивает точный ID, не ожидая обновления всего набора коллекции. Если запрос не удался, остаётся обычный путь через обновление набора. Это не гарантирует, что Telegram отдаст документ.

Изменения требуют обновления Android и развёртывания AuthBot. Android-сборка и проверка на устройстве для этой версии ещё не проводились; фактическая скорость на production не измерена. Время зависит от сети, наличия пользовательской MTProto-сессии и доступности конкретной анимации. Если файла нет в источниках, ускорение не может его создать. Происхождение и ограничения локальных fallback-файлов: `authbot/assets/gift_models/README.md`.
