# Интерфейс каналов и групп: исходный Telegram vs WaysGram
> **Исторический срез.** Это сравнение состояния до правки, которая удалила WaysGram-кнопки
> и вернула стоковые позиции. Текущее состояние описано в `docs/waysgram-fix-plan.md` и
> проверяется `scripts/test_android_stock_channel_group_buttons.py`.


Сравнение сделано по **фактическому исходнику сборки** — `WaysGram-Android.zip.part1…part5`.
Под «оригиналом» имеется в виду стоковая ветка Telegram Android внутри того же проекта: те же
классы `ChatActivity`, `ProfileActivity`, `ChatEditActivity` и их стоковые ветки, до WaysGram-правок.
APK не собирался; выводы статические, по коду и ресурсам.

Важно: `android-source/` — устаревшее зеркало (на момент проверки расходится с архивом примерно по
800 файлам), поэтому все строки ниже относятся к архиву, а не к зеркалу. Часть старых документов
(`channel-group-ui-parity.md`, `CHANNELS_GROUPS_GAP.md`) описывает желаемое состояние, которое в
архиве **не полностью воплощено** — см. раздел «Расхождения документации с кодом».

## Краткий вердикт

| Область | Telegram | WaysGram | Оценка |
|---|---|---|---|
| Каркас экранов | `ChatActivity` / `ProfileActivity` / `ChatEditActivity`, программная разметка | те же классы и та же разметка | **совпадает** |
| Меню «⋮» чата | стоковый порядок: уведомления, поиск, бусты, перевод, жалоба, обои, очистить, выйти | стоковые пункты в основном на месте; **бусты скрыты**; WaysGram-пункты добавлены в конец | **отличается** |
| Карточка канала/группы | карандаш редактирования, статистка, звонок, подарок, обсуждение в «⋮» | карандаш тот же; звонок скрыт, статистка и обсуждение — свои диалоги, подарок не показывается | **похоже, но поведение другое** |
| Экран «Изменить» | стоковые строки в стоковом порядке | стоковые строки в основном на месте, между «Администраторами» и «Подписчиками» вставлены 2–6 своих строк | **визуально отличается** |
| Комментарии к постам | родной тред, кнопка «Просмотреть комментарии» доступна читателям | свой REST-диалог; пункт в меню поста только у админов | **существенно отличается** |
| Платные реакции | настройка внутри «Реакции», звёзды Telegram | стоковый тумблер скрыт из-за незаполненного `paid_media_allowed`; есть свои входы в «Изменить» и меню поста | **входы подменены** |
| Нижняя панель канала | подписаться + поиск + подарок + «предложить пост» | подписаться + поиск; подарок и «предложить пост» скрыты из-за отсутствующих полей | **беднее стока** |
| Язык интерфейса (RU) | полностью переведён | в `values-ru` только 540 из 11 780 ключей; часть подписей английская | **заметно отличается** |
| Стиль диалогов | нативные bottom sheet / экраны | простые `AlertDialog` с текстом и кнопками | **отличается** |

## 1. Экран чата канала/группы

### 1.1 Меню «⋮»

Стоковые пункты строятся в исходном порядке и остаются на своих местах. WaysGram-пункты добавляются
последними (`ui/ChatActivity.java:4611-4629`):

* broadcast-канал: **Розыгрыши**, **Сообщения канала** / **Написать каналу**, **Темы канала**,
  **Payment history** (нет RU-перевода), **Бусты**;
* обычная группа: **Истории группы**, **Отправить от имени…**, **Темы**, **Бусты**.

В Telegram таких пунктов нет; они реализуют функциональность, для которой в стоке нет отдельного
входа. Зато стоковый пункт «Усилить канал/группу» (`boost_group`) полностью скрыт гейтом
`!WaysGramTransport.ENABLED` (`ChatActivity.java:4513-4518`), а вместо него в конец добавляется свой
«Бусты» — но только для broadcast-канала и обычной группы, не для мегагруппы.

### 1.2 Нижняя панель broadcast-канала

Условия видимости кнопок — стоковые (`ChatActivity.java:28164-28283`, `28542-28545`):

* `SEARCH` — включается как в Telegram;
* `GIFT` — требует `chatInfo.stargifts_available`; `WaysGramChats` это поле не выставляет, поэтому
  кнопки нет;
* `DIRECT` («Предложить пост») — требует `broadcast_messages_allowed && linked_monoforum_id != 0`;
  `linked_monoforum_id` WaysGram не заполняет, кнопки нет;
* основная кнопка «Подписаться / Уведомления» — стоковая.

То есть визуально остаётся только поиск вместо трёх плавающих кнопок Telegram.

### 1.3 Меню сообщения поста канала

В WaysGram добавлены два пункта (`ChatActivity.java:47037-47048`):

* **Платные реакции** — показывается для любого поста канала, открывает свой диалог с суммой и
  подтверждением списания внутренних Stars;
* **Группа обсуждений** — только владельцу/админу с правом менять информацию, открывает
  `WaysGramDiscussions` (список комментариев в `AlertDialog`).

В Telegram вместо второго пункта у читателя есть «Просмотреть комментарии» и родной тред с
ответами, реакциями и пагинацией. WaysGram-маппер поста тоже выставляет `replies.comments = true`,
если у поста есть `discussion_group_id` (`WaysGramChats.java:285-297`), поэтому штатная кнопка
комментариев может появиться у читателя. Однако она ведёт в нативный тред через
`replies.channel_id`, а REST-диалог `WaysGramDiscussions` доступен только админу из меню поста.
Карточка канала показывает стоковый «View discussion» по `linked_chat_id`, но он просто открывает
группу как обычный чат (`ProfileActivity.java:7151-7160`), а не тред комментариев WaysGram.

## 2. Карточка канала/группы (`ProfileActivity`)

| Элемент | Telegram | WaysGram |
|---|---|---|
| Карандаш в шапке | редактирование канала/группы | тот же `ChatEditActivity` |
| «Начать голосовой чат / трансляцию» | `ChatObject.canManageCalls(chat) && chatInfo.call == null` | скрыт гейтом `!waysGramBroadcast` (`ProfileActivity.java:12466,12482,12564`) |
| «Статистика» | только по `can_view_stats` / `can_view_revenue`, открывает `StatisticActivity` | дополнительное условие `waysGramStatistics` для админов; открывает свой диалог аналитики (`ProfileActivity.java:2812-2824`) |
| «Подарок каналу» | по `chatInfo.stargifts_available` | поле не заполняется маппером — кнопка не появляется |
| «Открыть обсуждение» | по `linked_chat_id` | поле заполняется из `discussion_group_id` (`WaysGramChats.java:1509-1512`), пункт появляется, но открывает группу как обычный чат |
| «Медленный режим» | в настройках редактирования | отдельный пункт в «⋮» группы, подпись захардкожена русской строкой (`ProfileActivity.java:12587-12591`) |
| Имена/бейджи | premium/verified от Telegram | дополнительные цветные пилюли `WaysGramPeerBadges` (`Level 0+`, `WaysGram` и т.п.) |

Кнопки «Поделиться», «Выйти», «Удалить» и поиск по участникам остаются стоковыми и в том же порядке.

## 3. Экран редактирования (`ChatEditActivity`)

Стоковые строки (тип, пригласительные ссылки, реакции, администраторы, подписчики, заявки,
журнал событий и т.д.) создаются на своих местах. Отличия:

1. **Свои строки между «Администраторами» и «Подписчиками»** (`ChatEditActivity.java:1426-1428`):
   * канал: *Платные реакции*, *Аналитика канала*, *Настройки входящих канала*, *Передача канала*,
     *Темы канала*, для приватного канала ещё *Подписка*;
   * группа: *Права на отправку*, *Скрытые участники*, *Аналитика группы*.
   Часть из них дублирует другие входы: аналитика есть и в «⋮» карточки, платные реакции — и в
   «Реакции», и в меню поста.
2. Стоковая строка **«Статистика и бусты» скрыта**, когда включён WaysGram-транспорт
   (`ChatEditActivity.java:1402-1410`), вместо неё работает своя аналитика.
3. Стоковая строка **«Обсуждение» осталась на своём месте**, но по нажатию открывает
   `WaysGramDiscussions.settings()` — диалог привязки группы через REST, а не `ChatLinkActivity`
   (`ChatEditActivity.java:1010-1021`).
4. Групповые WaysGram-строки добавляются в самый конец (`1503-1509`) — здесь стоковый порядок
   сохраняется полностью.

На скриншотах это выглядит как привычный экран «Edit», где между стандартными строками внезапно
появляются русскоязычные диалоги привязки/входящих — именно так и устроено в коде.

## 4. Реакции и платные функции

* Стоковый чип реакций над сообщением и пункт «Реакция» в меню работают как в Telegram; отправка идёт
  через WaysGram-мост.
* Тумблер платных реакций внутри «Реакции» условие показа стоковое: `info.paid_media_allowed`
  (`Components/Reactions/ChatCustomReactionsEditActivity.java:318-334`). WaysGram-маппер заполняет
  только `full.paid_reactions_available` из `paid_reactions_enabled` (`WaysGramChats.java:1464-1465`),
  а `paid_media_allowed` (flag2 `FLAG_14`) не выставляет нигде. Поэтому в WaysGram-канале стоковый
  тумблер в «Реакции» **не показывается**, хотя отдельная строка «Платные реакции» в
  «Изменить» работает через свой REST-диалог. По той же причине скрыты стоковые входы платных
  медиа (`ChatAttachAlert.java:4039`, `ManageLinksActivity.java:927-938`).
* Платные сообщения в канал: цена в шапке/кнопке отправки и подтверждение через `402` — WaysGram-
  реализация, в стоке отдельного такого сценария нет.
* Все суммы — внутренние Stars WaysGram, не Telegram Stars.

## 5. Визуальный слой и локализация

* Иконки, `.drawable`, отступы и темы — стоковые; кастомный фон приложения изолирован по решению
  «кастомизация только фон».
* Диалоги WaysGram (`WaysGramDiscussions`, `WaysGramChannelInbox`, `WaysGramPaidReactions`,
  `WaysGramGroupTopics`, …) строятся на `AlertDialog` + `TextView`/`CheckBox`/`EditText`. Это
  заметно проще нативных bottom sheet Telegram: нет аватаров, форматированного текста, анимаций.
* Русская локализация неполная: `values/strings.xml` — 11 780 ключей, `values-ru/strings.xml` —
  540. Поэтому на русском экране «Edit» смешиваются английские `Reactions`, `Administrators`,
  `Subscribers`, `Recent Actions` и русские `Платные реакции`, `Группа обсуждений`. В оригинальном
  Telegram таких смешанных подписей нет.
* Дополнительные цветные пилюли рядом с именами (`WaysGramPeerBadges`) — полностью WaysGram-элемент.

## 6. Что совпадает с Telegram почти один-в-один

* Навигация: список чатов → `ChatActivity` → шапка → карточка `ProfileActivity` → карандаш →
  `ChatEditActivity`; жесты и переходы остаются стандартными.
* Порядок и условия большинства стоковых пунктов меню «⋮» чата, карточки и экрана редактирования.
* Стоковые экраны `ChatEditTypeActivity`, `ManageLinksActivity`, `ChatUsersActivity`,
  `TopicsFragment`, `ChannelAdminLogActivity` — WaysGram-правок там почти нет (1–4 ссылки на мост).
* Стоковые элементы: аватар/имя канала, описание, счётчики подписчиков/админов, пригласительные
  ссылки, администраторы, журнал, темы, уведомления, обои, перевод, жалоба, удаление/выход.

## Итог

По **каркасу и навигации** WaysGram почти повторяет Telegram: это тот же клиент с теми же экранами.
Отличия сосредоточены в трёх местах: (1) дополнительные WaysGram-пункты и строки, часть из которых
дублирует стоковые входы; (2) подмена части стоковых сценариев простыми диалогами со своим REST-API;
(3) неполная русская локализация и отсутствие серверных флагов, из-за которых стоковые кнопки
(подарок, «предложить пост», нативные бусты/статистика) не появляются.

Если цель — визуальный паритет, приоритет таких правок: убрать дублирующие входы, вернуть
стоковым кнопкам данные из бэкенда, перевести недостающие строки и заменить служебные `AlertDialog`
на нативные экраны.
