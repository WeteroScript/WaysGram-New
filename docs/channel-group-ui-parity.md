# Паритет расположения кнопок каналов и групп с Telegram

Задача: в каналах и группах кнопки должны стоять там же, где в оригинальном Telegram, а
включаться по тем же правилам. Правки внесены **в архив** `WaysGram-Android.zip.part1…part5`
(он — источник правды для сборки), миррор `android-source/` перегенерирован.
Сборка APK не запускалась.

## Итоговый порядок меню «⋮» в чате канала

1. Уведомления (свайп-пункт) — стоковая позиция
2. Открыть прямой чат — стоковая
3. Поиск — стоковая
4. Бусты — стоковая позиция, стоковое условие (`isBoostSupported && (premium || boosted || hasAdminRights)`) и **стоковое действие**: открывает `BoostsActivity` (транспорт WaysGram бусты не умеет — экран останется пустым/с нулями)
5. Перевод
6. Жалоба (не админ)
7. Обои
8. Очистить историю
9. Выйти
10. **WaysGram:** Розыгрыши · Входящие канала · Бусты сообщества (собственный id `waysgram_community_boosts`, стоковые «Бусты» больше не подменяет)

Для группы пункты 1–9 те же, далее: **WaysGram:** Истории группы · Идентичность · Темы · Бусты сообщества.

## Что теперь включается по стоковым правилам

| Элемент | Условие (как в Telegram) | Следствие для WaysGram |
|---|---|---|
| «Начать голосовой чат / трансляцию» (карточка) | `ChatObject.canManageCalls(chat) && chatInfo.call == null` | появится у владельца/админа; сам звонок бэкенд пока не умеет — вернётся ошибка транспорта |
| «Архив историй» (карточка) | `canPostStories(chat) || canEditStories(chat)` | зависит от того, что отдаёт `WaysGramStories` |
| «Бусты» в чате и в списке тем | `isBoostSupported && (premium || boosted || hasAdminRights)` | показывается как в Telegram; открывает стоковый `BoostsActivity`, данные бустов бэкенд не отдаёт |
| Позиция кнопок «Поделиться/Пожаловаться/Выйти» в карточке | `ProfileActionsView` раскладывает по количеству | считается по видимым кнопкам, порядок стоковый |

## Что осталось зависящим от сервера (клиент больше не мешает)

Эти кнопки включаются только если бэкенд пришлёт соответствующие поля в `TL_channelFull`.
`WaysGramChats.fullChannel` их сейчас не заполняет, поэтому кнопки не появляются — но правила
показа уже стоковые, и достаточно начать отдавать поля:

| Кнопка / пункт | Нужное поле `TL_channelFull` / `TLRPC.Chat` |
|---|---|
| 🎁 «Подарок» в нижней панели чата и в карточке | `stargifts_available` |
| 💬 «Предложить пост» в нижней панели | `chat.broadcast_messages_allowed` + `chat.linked_monoforum_id` |
| Круглая кнопка «Обсуждение» и пункт «Открыть обсуждение» | `linked_chat_id` |
| «Статистика» в карточке | `can_view_stats`, `can_view_revenue` |
| Строка «Администраторы» с количеством | `admins_count` |
| Блокировки/жалобы с количеством | `banned_count`, `kicked_count` |

## Стоковые кнопки восстановлены (этот коммит)

Гейты `!org.telegram.tgnet.WaysGramTransport.ENABLED &&` убраны, поэтому штатные элементы
Telegram снова появляются по стоковым условиям и на стоковых местах:

| Элемент | Файл | Что делает при нажатии |
|---|---|---|
| «Обсуждение» / «Связанный канал» | `ChatEditActivity` (~1000) | стоковый `ChatLinkActivity` (транспорт `channels.editLinkedChat` не реализует — сохранение вернёт ошибку) |
| «Автоперевод канала» | `ChatEditActivity` (~1039) | стоковая логика бустов; при `boostsStatus == null` чекбокс возвращается в исходное состояние и спиннер закрывается |
| «Цвет имени канала» / «Цвет группы» | `ChatEditActivity` (~1162) | стоковый `ChannelColorActivity` / `GroupColorActivity` |
| «Статистика и бусты» | `ChatEditActivity` (~1380) | стоковый `StatisticActivity` (запросы `stats.*` транспорт не поддерживает) |
| «Бусты» в списке тем группы | `TopicsFragment` (~1508, ~2641) | стоковый `BoostsActivity` |
| Панель реакций под сообщением и кнопка «реакция» в меню | `ChatActivity` (~31500, ~31502) | стоковая доступность реакций; отправка идёт через `TL_messages_sendReaction`, который транспорт реализует (`WaysGramMessages.setReactions`) |

Меню «⋮»: пункт «Бусты» снова открывает стоковый `BoostsActivity`, а WaysGram-диалог бустов
сообщества переехал в собственный пункт `waysgram_community_boosts` в конце списка.

Строки экрана редактирования, которым нужны бусты/статистика/привязанный чат, показываются,
даже если бэкенд WaysGram эти запросы не обслуживает: по решению пользователя кнопка должна
выглядеть и стоять как в Telegram, а не исчезать.
