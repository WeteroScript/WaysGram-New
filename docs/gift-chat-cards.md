# Карточки переданных коллекционных подарков

Для личной передачи улучшенного WaysGram-подарка API хранит уровень и снимок характеристик в `message_gifts`. История дополнительно возвращает идентификатор экземпляра и присвоенный в WaysGram номер коллекции; для старых сообщений они берутся по серийному номеру, если запись ещё существует. Серийный номер не подставляется вместо неизвестного номера коллекции.

Android преобразует такую передачу в `TL_messageActionStarGiftUnique` с теми же моделью, узором и фоном, что используются в профиле. Обычные подарки остаются обычными карточками, а внутренний владелец меняется только через существующий WaysGram API. Нативные операции Telegram/TON из карточки WaysGram не используются. Карточка показывает получателя на момент передачи, а не удостоверяет текущего владельца после последующих передач.

Анимации загружаются асинхронно по сохранённым атрибутам. Видимая карточка обновляется после загрузки; пока файл недоступен, чужая модель или обычный стикер не подставляются. Данные для обновления отображения хранятся в ограниченном кеше процесса; после его очистки или перезапуска нужны актуальные данные истории. Если открытая панель подробностей не успела получить анимацию, её может понадобиться открыть заново. Отсутствующий в источнике файл не создаётся.

Изменение требует развёртывания нового AuthBot (для корректного номера) и нового APK. Проверки исходников не являются компиляцией или тестированием пользовательского интерфейса: оба направления передачи, повторное открытие истории, загрузку анимации и старые сообщения необходимо проверить на устройствах.
