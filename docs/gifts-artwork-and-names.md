# Plush Pepe и названия подарков

## Картинка

Для исходного Telegram Gift ID `5936013938331222567` AuthBot отдаёт локально сохранённые TGS и PNG оригинального неулучшенного подарка. Это устраняет зависимость изображения от старой ссылки Telegram и наличия авторизованной сессии при открытии магазина и обычного подарка. Запрос по-прежнему требует авторизации. Происхождение, контрольные суммы и ограничение по лицензии указаны в `authbot/assets/gifts/README.md`. Локальный файл не подменяет конкретные модели улучшенных подарков: они загружаются отдельно.

Если локальный файл отсутствует, работают прежние источники Telegram и MTProto. Доступность пользовательской MTProto-сессии и реальных файлов остальных подарков здесь не проверена.

На Android экран отправки слушает обновление каталога и повторно устанавливает документ картинки в уже открытой карточке, если документ изменился. Это исправление доставляется только вместе с новой APK; его синтаксис и структура проверены статически, но сборка и устройство не проверялись.

## Названия

В общую функцию объединены правила нормализации названий AuthBot, каталога и MTProto. Настоящее название из источника имеет приоритет; при отсутствии осмысленного имени используется проверенное соответствие ID → название из `gift_upgrade_pools.json` (имена коллекций из сохранённого дампа). Для неизвестных ID можно показать читаемый short name или, если его нет, нейтральный идентификатор. Short name — технические данные, он не всегда является официальным названием обычного подарка. Общее имя набора `TelegramGifts` больше не превращается в `s`.

Когда один и тот же подарок есть в обоих каталогах, админ-панель и метаданные покупки выбирают более качественное название, не меняя при этом источник остатка и цены. Текущие некорректные записи в базе не переписываются — имя нормализуется при выводе и следующей синхронизации.

Необходимы обновление/развёртывание AuthBot и последующая Android-сборка; ранее установленная APK не получает изменения Java автоматически. Фактическое отображение на устройстве и работа в production не проверены.
