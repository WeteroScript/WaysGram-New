# Редактирование сообщений и порядок подарков

Нативный мост текстового редактирования отправляет PUT (сервер принимает его наряду с PATCH) для личных сообщений, включая «Избранное», групп и каналов. Это обходит возможную несовместимость PATCH в Android `HttpURLConnection`. Права и ограничения остались на сервере. Вместо универсальной ошибки Telegram WaysGram показывает причину отказа или ошибку связи. Отдельная ошибка получения обновлённой истории после успешного изменения также возможна, поэтому сообщение об ошибке не всегда означает, что запись не сохранилась. Редактирование медиа и форматирование этим изменением не расширены.

В своём профиле карандаш включает сортировку. Долгое нажатие начинает перенос карточки; второй палец прокручивает сетку. При отпускании первого пальца подарки в начальной и конечной ячейках меняются местами, после чего порядок сохраняется через API. Отмена жеста не сохраняет перемещение. При сетевой ошибке список перезагружается с сервера. Пока идёт сохранение, следующее перемещение заблокировано.

Проверки исходников и API не заменяют тестирование на устройстве: жесты, долгие списки, сортировка после прокрутки и отображение обновлённого сообщения нужно проверить в новом APK. Выполнявшаяся ранее сборка с оптимизацией загрузки эти исправления не содержит.
