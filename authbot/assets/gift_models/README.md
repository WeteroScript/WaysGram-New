# Heart Locket model artwork fallback

The files under `5868455043362980631/` are 29 TGS animations matched by exact
model name against the Heart Locket pool in `gift_upgrade_pools.json`. They
were obtained from the third-party repository
[ssamy2/TelegramGiftsAssests](https://github.com/ssamy2/TelegramGiftsAssests)
at commit `1eb0666fff81b63f9002004084ff0ee3a9eed10f`. Its README states that
images are free to use; it does not establish the rights to Telegram's
animations. Verify the underlying rights before distributing them.

`manifest.json` records the source, SHA-256 and byte size of every file, plus
Telegram document IDs only where explicitly given in the source's config.
The negative `document_id` values are synthetic WaysGram identifiers, not
Telegram IDs. Files were checked as gzip/Lottie animations; the source's
filename-to-model mapping is third-party data and not an official Telegram
attestation.

White Wolf, Shaman and Pluto from the current 32-model pool were not in this
source and have deliberately not been replaced with an arbitrary model. This
pack does not contain symbols/patterns and cannot help if the gift's recorded
name/ID cannot be identified. Full Telegram MTProto data remains the preferred
source when available.
