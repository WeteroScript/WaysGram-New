# Локальное изображение Plush Pepe

`5936013938331222567.tgs` и `.png` — анимация обычного подарка Plush Pepe и её статичный кадр, сохранённые по Telegram Gift ID. Они отдаются только авторизованным пользователям через обычный endpoint `/api/telegram/gifts/{id}/sticker`: TGS для `animated=1`, PNG для обычного запроса. Они не используются вместо моделей конкретного улучшенного подарка.

Файлы взяты из публичного каталога [denzyve/cdn-telegram-gifts](https://github.com/denzyve/cdn-telegram-gifts) на коммите `5c17383f771258c004a02c78019ac2616f482d6c`; его `data/gifts.json` связывает оба файла с этим ID и указывает, что TGS — оригинальная анимация, PNG — её кадр. У репозитория источника явная лицензия не указана; права на изображение необходимо проверять у правообладателей перед распространением.
